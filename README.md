# VisualBoost

VisualBoost는 Visual Studio에서 파일·심볼 탐색과 C++ 편집 작업을 지원하는 확장 프로그램입니다. 파일 탐색은 다양한 언어의 프로젝트에서 사용할 수 있습니다.

## 현재 기능

### 단축키

- `Alt+O`: 헤더·구현 파일 전환
- `Shift+Alt+O`: 파일 탐색
- `Shift+Alt+S`: C++ 심볼 탐색 — 전체·프로젝트·엔진 범위 선택
- `Alt+M`: 현재 C++ 파일의 함수 탐색
- `Shift+Alt+Q`: C++ 코드 도구 — 선언·정의 생성, 빠른 인클루드
- `Ctrl+클릭`: 주석 링크 이동 — C++·C# 파일명/라인, C++ 클래스·네임스페이스·한정 함수 이름

### 옵션 기능

`Tools > Options > VisualBoost`에서 설정할 수 있습니다.

- `Coloring`: C++ 타입·변수·매크로·이넘 멤버·함수/메서드·네임스페이스 색상 지정
- `자동완성`: C++ 이름 자동완성

## 프로젝트 상태

현재 초기 개발 단계입니다. 복잡한 C++ 구문에서는 일부 기능이 제한될 수 있으며, 생성하거나 추가한 코드는 확인 후 저장해 주세요.
