# VisualBoost

VisualBoost는 Visual Studio에서 빠른 파일·심볼 탐색과 C++ 편집 작업을 지원하는 확장 프로그램입니다. 파일 탐색은 다양한 언어의 프로젝트에서 사용할 수 있습니다.

## 현재 기능

- `Alt+O`: 현재 헤더와 동일한 이름의 구현 파일 또는 현재 구현 파일과 동일한 이름의 헤더로 전환
- 헤더·구현 전환 후보가 여러 개면 탐색 창에서 원하는 파일 선택
- `Alt+G`: 선언·정의 이동. C++ 함수 이름의 정의 위치와 대응 선언을 확인할 수 있으면 선언으로 이동하고, 나머지는 Visual Studio의 기본 정의 탐색 사용
- `Shift+Alt+Q`: 키보드 커서 위치에 현재 코드 도구 드롭다운 표시. 선언에서는 `정의 생성`, 정의에서는 `선언 생성`을 제공하며 대응 코드가 이미 있으면 메뉴 없이 알림음만 재생
- `Tools > Visual Boost` 및 코드 편집기 우클릭의 `Visual Boost > 현재 코드 도구...`에서 같은 명령 실행
- 같은 프로젝트의 1순위 기존 대응 파일을 자동 선택하고 메뉴에서 선택 즉시 삽입. 선언 생성의 `public`·`protected`·`private`는 하위 메뉴에서 선택
- `Tools > Options > VisualBoost > 코드 생성`에서 기능 사용 여부 설정
- `Shift+Alt+O`: 파일명과 경로를 검색하는 키보드 중심 파일 탐색 창 열기
- `Shift+Alt+S`: C++ 선언·정의 후보를 검색하는 퍼지 심볼 탐색 창 열기
- `Alt+M`: 현재 C++ 문서의 함수 목록을 검색하고 해당 라인으로 이동. 열 때 키보드 커서가 속한 함수를 먼저 선택
- 문서 함수 탐색은 별도 상단 바 없이 동작하며 미저장 편집 내용·분할 편집창을 반영하고 전체 솔루션 분석과 독립적으로 동작
- 문서 함수 목록은 이름·종류·라인을 표시하고 공백 AND 검색, 열 너비 조절, 일치 문자 강조와 색상 설정 공유 지원
- `Tools > Options > VisualBoost > 문서 함수 탐색`에서 목록 이름순 정렬 설정
- 심볼 결과를 심볼명·종류·파일·라인·프로젝트 순으로 표시하고 열 너비 비율 조절 지원
- 기본 IntelliSense가 열려 있지 않을 때 C++ 인덱스 기반 이름 자동완성 제공: 3글자부터 제안하고 `↓`로 선택 후 `Tab`으로 삽입
- 자동완성은 `Enter`·문장부호로 확정하지 않으며, `.`·`->`·`::` 뒤의 타입 기반 추천에는 개입하지 않음
- `Tools > Options > VisualBoost > 자동완성`에서 사용 여부·최소 입력 길이·대기 시간 설정
- 최근에 연 파일과 현재 프로젝트의 파일을 검색 결과에서 우선 표시
- 파일 검색은 모든 검색어가 파일명에 포함된 후보를 먼저 표시하고, 파일명 퍼지 일치와 경로 일치 순서로 정렬
- 검색어가 없을 때 최근 파일과 현재 프로젝트 파일을 바로 표시
- `전체`, `현재 프로젝트`, `열린 파일`, `외부 소스` 검색 범위 제공
- 파일 형식, 상대 경로, 결과 출처, 검색어 일치 구간 및 인덱싱 상태 표시
- 검색 결과에서 열기, 전체 경로 복사, 탐색기에서 보기를 제공하는 컨텍스트 메뉴
- 검색 중 `Esc` 또는 취소 버튼으로 대규모 검색 중단
- Solution 로드 시 언어와 관계없이 프로젝트 파일을 백그라운드 인덱싱
- 프로젝트 파일과 C++ include 경로 및 감지된 외부 엔진 소스 인덱싱
- `%LocalAppData%\\VisualBoost\\Cache`의 Solution별 영구 파일 캐시
- C++ include 관계와 주요 심볼 후보 위치의 증분 분석 및 로컬 캐시
- 파일 생성·삭제·이름 변경을 실행 중인 인덱스에 증분 반영
- 실행 중 추가·제거·이름 변경된 프로젝트의 검색 루트 반영
- 동일 디렉터리와 `include`/`src` 같은 대응 디렉터리를 우선하는 후보 점수 계산
- `Tools > Options > VisualBoost > General`에서 C++ 확장자와 대응 디렉터리 설정
- `Tools > Options > VisualBoost > 파일 탐색`에서 결과 수, 입력 지연과 빈 검색 추천 설정
- `Tools > Options > VisualBoost > 인덱싱`에서 영구 캐시, 소스 분석과 진단 설정
- `Tools > Visual Boost` 하위 메뉴에서 탐색 명령, 옵션과 인덱스 상태에 접근
- `Tools > Options > VisualBoost > Coloring`에서 색상 견본과 팔레트 선택 창으로 C++ 의미 색상 설정
- `Coloring`의 색상 설정 기준을 `FontsAndColors`로 선택하면 `환경 > 글꼴 및 색 > 텍스트 편집기`의 테마별 `VisualBoost` 전경색 사용
- C++ 편집기와 심볼 탐색에서 색상 설정을 공유하며, 선택 행과 고대비 모드의 기본 강조색 유지
- `.git`, `.vs`, `bin`, `obj`, `packages`, `node_modules` 및 대형 생성물 디렉터리 제외

## 프로젝트 상태

VisualBoost는 현재 초기 개발 단계입니다. 기능 지원 범위는 위의 `현재 기능` 목록을 기준으로 합니다. C++ 심볼 탐색은 선언·정의 후보 인덱스를 사용하며, 파일 탐색과 구분됩니다.

문서 함수 탐색은 편집 버퍼를 읽는 경량 구문 탐색입니다. 매크로 확장으로 생성된 함수와 복잡한 C++ 구문은 일부 누락될 수 있고, 조건부 컴파일의 활성 분기를 판정하지 않습니다. 소스 파일을 수정하거나 저장하지 않습니다.

선언/정의 생성은 Visual Studio의 동기화된 C++ 언어 모델로 소속을 확인할 수 있는 일반 비템플릿 `class`·`struct` 멤버를 대상으로 합니다. 같은 프로젝트의 기존 파일만 사용하며, 템플릿·복잡한 매크로·조건부 컴파일 등 미지원 구문이나 불확실한 오버로드는 수정 없이 안내합니다. 언어 모델이 준비되지 않은 프로젝트에서는 사용할 수 없습니다.

생성은 별도 파일 선택이나 미리보기 없이 바로 적용하며 한 번의 Undo로 되돌릴 수 있습니다. include가 없어도 생성하지만 필요한 헤더 의존성은 직접 추가해야 합니다. 자동 저장·파일 생성·include 추가·프로젝트 설정 변경은 하지 않으며, 외부·생성·읽기 전용 파일은 제외합니다. 반환값이 필요한 함수에는 미완성을 표시하는 `static_assert(false)`를 넣으므로 본문 구현 후 제거해야 합니다.
